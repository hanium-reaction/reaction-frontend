# 중단 상황 입력 간소화

## 이번 변경

- 전체 카탈로그 대신 시간·피로·막막함·분량에 해당하는 항목을 최대 네 개 먼저 표시한다. 실제 빈도 순위나 진단 결과를 뜻하지 않는다.
- 나머지 코드와 서버 라벨은 `다른 상황`에 그대로 보존한다. 서로 다른 태그를 임의로 통합하지 않는다.
- 오늘·집중 화면에서 무응답으로 다음 행동을 볼 수 있다. 미응답을 기타·회피·피로 등의 태그로 바꾸지 않는다.
- 메모와 회피 정도는 추가 입력으로 접는다. 피곤함이나 시간 부족에 회피 점수를 붙이지 않는다.
- 저녁 체크인도 같은 폼을 사용하고, 입력하지 않으면 항상 같은 제안이 나온다는 단정적 문구를 제거한다.

## 해석과 제한

선택 태그는 사용자가 보고한 당시 상황이다. 객관적인 실패 원인, 심리 진단, 서비스 효과를 측정하는 지표로 간주하지 않는다. 원인 비율을 분석한다면 미응답과 응답자 비중을 구분해야 한다.

현재 API 계약은 메모만 전송하면 422를 반환한다. 따라서 독립적인 자유 서술 저장은 이번 변경에 포함하지 않는다. 태그가 없는 메모 초안은 지우거나 임의 분류하지 않고, 선택 또는 메모 삭제가 필요하다고 알린다. 태그와 메모가 모두 비면 기존 실행 결과 저장 후 일반 재계획 경로를 사용한다.

카탈로그 장애 시 기존 fallback 동작은 유지한다. 이번 UI 개선으로 신규 자연어 분류 모델이나 사용자 효과 검증을 구현한 것은 아니다.

## 검증

공통 폼의 표시 개수, 신규 서버 태그 보존, 미응답, 메모 보호, 회피 점수 정리와 집중 화면의 무응답 전달을 회귀 테스트로 검사한다. 320px 및 390px 모바일 뷰에서 기본/추가 입력 화면을 확인한다.
