# 재실행 P1 연결

P0의 재실행 경로를 재사용한다. `VITE_REENTRY_P0=true` 활성화 전에 백엔드 P0/P1 migration/API가 준비되어야 한다. 플래그 기본값은 false다.

- FE07: 빠른 시작(작업/첫 행동/이번 시도 시간), 계정·목표별 탭 임시 저장, 재전송 ID 유지. 상세 인터뷰 계속 사용.
- FE08: 메모만 저장 가능. 기존 체크인 배치 API 재사용. 미입력 진행률을 시간으로 계산하지 않음.
- FE09: 설정 요약/나중에 설정, 브라우저 권한과 서버 구독 상태 구분. 실제 발송 보장 문구 없음.
- FE10: 작업 자료 연결/수정/해제, 마지막 실행 메모 표시. 원본 자료 수집/완료 처리 없음.
- FE11: 기존 회복 단계와 선택 근거 표시, 목표 검토 이동, 기존 승인/거절/쉬기 경로 유지.
- FE12: 주간 실제 재실행 건수, 표본 부족 안내, 명시적 선호 저장/철회. 선호는 안내이며 일정을 자동 변경하지 않음. 습관 빈도 변경 실패는 숨기지 않음.

`tests/integration/reentry.html`은 개발 전용 실제 화면/HTTP 클라이언트 연결 하네스다. 백엔드 메모리 저장 어댑터와 함께 사용하며 PostgreSQL 영속성/소유권은 백엔드 CI에서 별도 확인한다. 실제 사용자 효과, 운영 OAuth·푸시 전달, 결제/보상 효과를 검증했다는 뜻은 아니다.
