# Linear UI 참고와 Re:Action 적용 범위

확인일: 2026-10-05

## 가져온 방식

- Linear My Issues의 관련 작업별 뷰: 오늘 목록에 전체·예정·재계획·완료 필터와 건수를 표시한다. 예정에는 진행 중인 작업도 포함한다.
- 목록에서 맥락을 잃지 않는 Peek: Re:Action은 키보드 전용 동작 대신 터치·키보드 모두 가능한 접이식 상세를 제공한다. 펼치기만 해서는 실행·완료·재계획 API를 호출하지 않는다.
- 필요한 작업 찾기: 제목·목표 검색과 상태 필터를 함께 적용한다. 검색 결과가 없어도 조건 초기화로 돌아갈 수 있다.
- 모바일은 상태를 색상뿐 아니라 글자로 표시하고, 44px 이상 조작 영역과 긴 제목 줄바꿈을 유지한다.

## 다르게 설계한 부분

Linear의 팀 이슈 관리 기능을 열등하다고 비교하지 않는다. 제품의 목적이 다르다. Re:Action은 개인 작업의 중단 사유·반복 이력을 바탕으로 다음 행동을 다시 정하는 흐름을 강조한다. 큰 실행 버튼, 첫 행동, 중단 사유, 재계획 후보, 사용자 승인, 후속 실행 기록은 유지한다. 이번 목록 UI가 재계획 알고리즘이나 사용자 성과를 개선했다고 주장하지 않는다.

## 이번 변경의 경계

오늘 목록과 해당 컴포넌트만 변경했다. 목표·루틴 카드 크기나 주간 캘린더는 축소하지 않았다. 주간 fallback은 읽기 전용으로 유지하고 고정 일정에는 재계획 버튼을 제공하지 않는다. 새 백엔드·유료 기능·푸시 알림·자동 일정 변경을 추가하지 않았다.

## 확인

컴포넌트 회귀 테스트: 6개 상태의 분류, 검색·초기화, 미리보기의 비변경성, 읽기 전용, 고정 일정, 상태 갱신. 전체 테스트·API 계약·빌드 확인 후 머지한다. Chrome에서 320px·390px 모바일와 데스크톱을 확인하고, 발표용 캡처는 운영 배포 이후 따로 취득한다. 로컬 합성 데이터는 운영 화면 캡처로 사용하지 않는다.
