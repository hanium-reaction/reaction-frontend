## 로컬 브라우저 확인

Chrome에서 실제 `RecoveryScreen`·`RecoveredScreen`을 임시 테스트 화면에 띄웠습니다. API와 상위 화면 연결은 대체했으며 운영 서버는 호출하지 않았습니다. 테스트 화면은 제출 코드에 포함하지 않습니다.

- 이전 카드 선택 → 다른 제안 → 의도한 조회 오류: 기존 카드가 사라지고 ‘이 방법으로’ 비활성화 확인
- 다시 시도 → 새 카드 선택 → 선택 저장: 복구 변경 미리보기로 연결 확인
- 변경 예정 안내 → 일정 반영하기: 승인 성공 콜백으로 복귀 확인
- 기록 없는 진입: 회복 기록 없음 안내와 오늘로 돌아가기 버튼 확인

실제 앱 전체를 정상 로그인부터 끝까지 실행한 E2E 검증은 아닙니다. 자동 테스트와 함께 수정된 화면의 동작을 확인한 결과입니다.
